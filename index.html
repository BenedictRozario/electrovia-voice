Talk to the ElectroVia AI agent to check, change or cancel an order. Use the call button on this page to start.

How to test the agent

  1. Click the call button and allow microphone access when your browser asks.
  2. When prompted, say English (or Deutsch for German).
  3. Verify your identity by giving the order number, postal code and phone number below.
  4. Ask the agent to check an order status, change an order or cancel an order.

Prefer to type? Use the chat button at the bottom right. The call button is the voice agent being evaluated; the chat window is a text-only alternative.
